PUBLISH WITH FREE GITHUB PAGES
1. Extract this ZIP.
2. In your GitHub repository, choose Add file > Upload files.
3. Upload index.html and style.css (and this README if you like) into the repository's main/root folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish and use the website URL shown in Settings > Pages.
